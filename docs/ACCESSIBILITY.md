# تقرير الوصول — WCAG 2.2 AA

**آخر فحص:** 27 أغسطس 2026 · **النتيجة: 15/15 صفحة بلا أي مخالفة**

## المنهجية

فحص آلي بمحرك [axe-core](https://github.com/dequelabs/axe-core) (قواعد
`wcag2a` + `wcag2aa` + `wcag21aa` + `wcag22aa`) عبر متصفح Chromium حقيقي،
بالسكربت المرفق في المستودع:

```bash
php artisan serve --port=8000 &        # خادم محلي بقاعدة مبذورة
BASE_URL=http://127.0.0.1:8000 npm run axe
```

يفشل السكربت (رمز خروج 1) عند وجود أي مخالفة — شغّلوه قبل كل إصدار.

## ما أصلحه الفحص الأخير

- **بنية قائمة التفاصيل في صفحة الفعالية** (`definition-list` + `dlitem`
  بدرجة serious): كانت `<dt>/<dd>` متداخلة داخل `div` ثانٍ بسبب أيقونة
  التخطيط، فنُقلت الأيقونة داخل `<dt>` نفسها وأصبحت البنية مطابقة للمواصفة
  مع الحفاظ على الشكل.

## الضوابط الدائمة في القوالب

- تباين ألوان مضبوط عبر متغيرات التصميم في `resources/css/app.css`.
- حالة تركيز مرئية لكل عنصر تفاعلي، والتنقل الكامل بلوحة المفاتيح.
- تسميات `aria-label` لأزرار الأيقونات، و`alt` لكل صورة محتوى.
- `prefers-reduced-motion` يعطّل الحركات، و`<noscript>` يبقي المحتوى مقروءاً.
- الاتجاه RTL أصيل في كل الصفحات، والحقول الرقمية `dir="ltr"` حيث يلزم.

## حدود الفحص الآلي

axe يكشف نحو ٦٠٪ من مشاكل الوصول. المتبقي يحتاج تجربة يدوية بقارئ شاشة
(TalkBack على أندرويد هو الأشيع لدى جمهور المنصّة) — موصى بها عند أي
تعديل كبير على الواجهة.
