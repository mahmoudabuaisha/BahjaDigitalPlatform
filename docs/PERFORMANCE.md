# ميزانيات الأداء — العقد والقياس

**آخر قياس:** 27 أغسطس 2026 · **النتيجة: كل الأصول ضمن الميزانية**

المنصّة تخدم عائلات على شبكات ضعيفة ومتقطعة، فميزانية الصفحة الأولى
عقدٌ صريح يفشل البناء عند خرقه — لا تمنٍّ.

## الحدود المعلنة (تُعدَّل في `scripts/check-budgets.mjs` فقط)

| الأصل | الحد | المقاس حالياً |
|---|---|---|
| JavaScript الكلي (قبل الضغط) | 88KB | **52.0KB** |
| CSS الكلي (قبل الضغط) | 117KB | **69.5KB** |

| خط الويب | خط عربي واحد مقتطع | Tajawal subset ~27KB |
| مكتبات JS خارجية ثقيلة | صفر | صفر (Alpine مضمّن في الحزمة) |

## التشغيل

```bash
npm run build && npm run budgets
```

رمز الخروج 1 عند أي تجاوز — أضيفوه قبل أي نشر (وفي CI حين يتوفر).

## قرارات معمارية تخدم الميزانية

- **صور البطاقات WebP بعرض 640** تولَّد آلياً مع كل رفع (ImageService)،
  والأصل JPEG بحد 1600px — لا تصل صورة هاتف خام (عدة ميغابايت) للزائر أبداً.
- **الرسوم التوضيحية SVG مضمّنة** لا صور نقطية.
- **snapshot الأوفلاين** بعقد ETag/304 — الزيارة المتكررة لا تعيد تنزيل
  ما لم يتغيّر، والكاش المحلي يخدم فوراً.
- **بلا CDN خارجي**: كل الأصول من نفس النطاق (مناسب أيضاً لتقلب الوصول
  للخدمات الخارجية من القطاع).
- على الخادم: OPcache مفعّل افتراضياً في هوستنغر + `php artisan optimize`
  مع كل نشر (كاش الإعدادات والمسارات والقوالب).

## ما يتجاوز حدود هذا القياس

القياس أعلاه يقيس حجم ما يُنقل — وهو المتغيّر الذي نتحكم به من الكود.
قياس زمن التحميل الميداني على أجهزة حقيقية داخل غزة يتطلب جمهوراً حقيقياً؛
عند توفر الإحصاءات من الاستخدام الفعلي يُستكمل هذا الملف بأرقام ميدانية.
